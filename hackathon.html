🛠️ 작업 결과물

사내 시스템 통합 Workflow + AI Agent

분산된 사내 시스템을 하나로 통합하는 Workflow 개발과 AI Agent 통합 개발 과제를 진행.

🏭 Dark Factory 지향 — 사람이 직접 라인에 들어가지 않고 모든 공정이 자동화되는 무인 공장. 이 작업은 회사가 나아가는 방향성의 핵심 인프라를 코드로 구축하는 것.

주요 기술 스택

💡 해커톤에서 배운 것

1

아이디어 공유는 정말 중요함

소통을 안 하면 안 됨. 팀원 간 아이디어가 공유되지 않으면 각자 다른 방향으로 일하게 됨.

2

참가 전 충분한 토론이 있어야 함

코딩 시작 전에 팀 전체가 같은 그림을 보고 있어야 함. 충분한 토론 없이 시작하면 중간에 방향이 갈림.

3

기능을 만들려고 하면 안 됨

해커톤에서 하나의 기능만 만들어도 대단한 거임. 빠르게 제작해서 빠르게 전달해야 하기 때문. 욕심내서 여러 기능을 만들려고 하면 하나도 완성 못 함.

4

AI에게 맡기지 마셈

내 머릿속에 없는 걸 AI에게 맡기지 마셈. AI와 함께 고민은 해 볼 수 있음. 하지만 방향과 아이디어는 사람이 가져야 함.

5

팀 전원이 같은 생각으로 일해야 함

리더를 포함 팀원 전원이 같은 생각을 가지고 일해야 함. 한 명이라도 다른 방향을 보면 결과물이 파편화됨.

"내 머릿속에 없는 걸 AI에게 맡기지 마셈.
함께 고민은 해 볼 수 있음."
