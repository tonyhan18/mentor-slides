회사를 고르는 기준

💡 한 명의 사람은 절대 회사를 이길 수 없고, 회사는 산업을 이길 수 없고, 산업은 시장을 이길 수 없다.

Top-Down 방식

  • 시장: 한국장 → 이미 결정됨
  • 산업: 섹터 중 1등 = 반도체
  • 회사: 삼성전자 / SK 하이닉스
  • 산학 혜택 → 미치도록 준비

개인의 선택

  • 단체에 묶이는 방향 선택 (개인 독고다이 vs 조직)
  • 삼성 SDS·카카오·토스 ← 다 합격했지만 삼전 선택
  • 개발자 성장은 본인이 알아서 → 재테크에 집중
  • 사업의 어려움을 일찍 깨달음 → 몸값 올리는 전략

재테크 공부의 결과

🏠 부동산

금리 인상기에 집값 하락 → 3억 6천에 매수 → 현재 7억 (약 2배)

📈 주식

반도체·AI·빅테크 장기 보유. 미국 반도체 + TOP10 빅테크만 집중 투자 → 대박

💰 자산

입사 4년 만에 자산 10억 돌파 → 20억으로 가고 있음

🧘 여유

자산이 쌓이니 이직에 대한 걱정이 사라짐. 어디서 일해도 OK

역설: 평범한 커리어는 "나"를 중심으로 돌아가지만, 나는 산업을 먼저 고르고 Top-Down으로 선택했다. 커리어에서는 떨어질 수 있어도, 자산적으로는 동기 중 최고일 수 있다.

05 / 08

확실하고 강력한 보상 체계

연봉 구조

  • 기본급은 상대적으로 낮음
  • 불황기에는 총소득 낮아질 수 있음
  • 호황기에는 직급 불문 5~6억+
  • 월급 14회 수령 (연 14개월)
  • 연말 성과급(OPI) = 연봉의 최대 50%

PSU (자사주 지급)

직급지급 주수
CL1 · CL2400주
CL3 · CL4600주

⚠️ 반도체는 사이클이 강한 산업. 연봉이 잘 쳐줄 때는 경쟁자도 다 안다 → 저평가 시기 진입이 유리

06 / 08

입사 전략 & 부서 바이 부서

입사 전략

구분유리한 조건 (순위)
신입석박사/산학장학생 > 인턴 > 일반 정규
경력유사 업계 하청 or 동급 이직 추천
비추천삼성 계열사 내 이동 (SDS→전자)

📌 학사 취업 시 반드시 인턴 거칠 것

부바부 (부서 바이 부서)

  • 어떤 선배를 만나느냐 → 직무가 갈림
  • 개발자 / 설비 엔지니어 / 시설 관리 / 서버 엔지니어
  • 시설 정비: 체크리스트 점검 → 대기 → 점검 → 퇴근, 연봉 1억+
  • 개발자보다 좋은 분야도 많음
  • 워라밸 + 결혼 + 육아 → 행복한 삶 가능

압도적인 업무 범위 & B2B 특성

🏭 자연 → 광물 → 원자재 → 설비 → 공장 → 하드웨어 → 반도체 → 인프라 → 소프트웨어 → AI

최하단부터 최상단까지 모든 스택을 자체 내재화하는 회사. 이렇게 모든 스택을 소화하는 회사는 흔치 않다.

⚠️ B2B 기업의 특성

대규모 일반 유저 트래픽(B2C)을 다룰 일은 거의 없는 철저한 B2B 회사. 이 점을 명확히 인지해야 한다.
